محتوى الأدوات في ذاكرة الصفحة

إعدادات محلية اختيارية

يمكن تذكّر اختيار اللغة على هذا الجهاز. عند تفعيل وضع التعلّم تُحفظ علامة تفعيله ومعرّفات المهام المكتملة فقط. لا توجد درجات صحية أو إجابات أعراض أو تتبع لسلاسل الاستمرار أو حسابات. يمكنك مسح التقدّم أو إيقاف الوضع.

الاستضافة والروابط الخارجية

تصل طلبات الويب العادية إلى GitHub Pages، بما فيها عنوان IP ومعلومات المتصفح. روابط مقدمي الخدمات وInstagram والمصادر تفتح خدمات أخرى تخضع لسياساتها. هي روابط وليست أدوات تتبع مضمّنة. تستخدم هذه النسخة خطوط النظام، دون تحليلات أو كود عرض إعلانات أو بكسلات تتبع أو ملفات تعريف ارتباط ينشئها الموقع. وسم ملكية AdSense وملف ads.txt لا يعرضان إعلانات.

قبل أي إعلانات مستقبلية

ستُراجع الإعلانات وخيارات الموافقة اللازمة بصورة منفصلة قبل تفعيل الكود. وسيُحدّث إشعار الخصوصية ليصف الخدمات الفعلية. لن يُستخدم محتوى الأدوات والمعلومات الصحية لإنشاء جمهور إعلاني مخصص.
