Privacy

Updated 13 October 2026. This notice describes the website features currently included in this version.

Browsing and searching

This site does not ask for an account, medical history, symptom answers or payment information. Directory searches and filters run in your browser; their text is not sent to the directory source. The website code does not store search queries or personal health information.

The directory downloads a public Google Sheets CSV and a site-hosted file of separately sourced provider details. Visiting the site and loading the CSV involves ordinary web requests, including your IP address and browser information, to the hosting provider (GitHub Pages) and Google. Those providers may maintain service and security logs under their own policies.

External links

Links to Instagram, YouTube, public health resources and provider pages take you to other services. Their privacy practices apply when you visit them. Videos and social media are linked rather than automatically embedded. We use system fonts so browsing does not require a Google Fonts request.

Advertising and cookies

This version contains an AdSense ownership meta tag and an ads.txt publisher entry. These do not load advertising scripts. The site currently has no ad-serving code, analytics code, tracking pixels or site-created cookies. If advertising is added, this notice and any required consent choices must be updated before that code is enabled.

Older browser storage

An earlier version stored directory edits and an admin password in the visitor's browser. This version does not read or use those values and cannot publish them. You can remove old values through your browser's settings for this site. Browser-only information was never a shared directory database.

Contacting the community

If you choose to message the community through Instagram, Meta processes your message under its own policies. Please keep corrections to public professional information. Do not send medical records, identifying health information or confidential details about another person.

For a privacy question or a listing correction, use the contact page.

External policies: GitHub, Google, Instagram.
